# ゲームデザイン・仕様案

> この文書は現時点の構想を整理したもの。明記されていない数値やルールは未確定であり、実装前に決定する。

## 1. タスク・勉強管理

プレイヤーは自分でタスクや勉強予定、実施時間を設定する。

想定機能：
- タスクの作成・編集・完了管理
- タスクごとの実施時間・勉強タイマーの設定
- 勉強予定、科目、タスク内容の登録
- 実行中の経過時間や進捗の確認
- 完了・継続などに応じた報酬の受け取り
- タスク実行時に派遣するキャラクターと戦闘先の選択

タイマーの開始だけで報酬を付与するか、完了確認を必要とするか、一時停止・未完了をどう扱うかは未決定。

### 中断と再開

中断したクエストは作業済みの内容を失わず、複数保持できる。

- タイマー式: 中断時点までの報酬を0.5倍で確定し、残り時間を保持したまま中断する。再開後は残り時間から継続し、完了時は再開後の作業時間分だけ報酬を付与する。
- ストップウォッチ式: 中断時点までの報酬を0.5倍で確定し、累計作業時間を保持したまま中断する。再開後は累計時間を表示しつつ、完了時は再開後の作業時間分だけ報酬を付与する。
- 中断中のクエストは一覧からいつでも再開できる。破棄した場合は追加報酬なしで予定に戻る。
- 中断中もタスクは削除できない。進行中の作業は同時に1件までとする。

### 作業履歴の削除

- 履歴画面から終了済みの作業セッションを削除できる。削除前に確認を表示する。
- 削除は作業時間の集計にのみ影響し、確定済みの報酬・タスクの完了状態・週次評価は変更しない。
- 削除直後は取り消しトーストから元に戻せる。

## 2. タスク内容による報酬決定

報酬は、タスク内容や勉強科目、難易度、実際に取り組んだ時間、完了状況、継続実績などをもとに決定する。

タスク名・説明・カテゴリ名・サブカテゴリ名から結晶タイプを判定するキーワード判定を正式な判定として扱う。

- カテゴリごとにユーザーが任意でキーワードを設定できる。タスク名・説明・サブカテゴリ名に含まれると、そのカテゴリの既定結晶タイプを優先する。
- ユーザーキーワードに一致しない場合は、組み込みキーワードの一致数・最長一致長・定義順で結晶タイプを決める。
- 組み込みキーワードにも一致しない場合は、カテゴリの既定結晶タイプを使う。未設定の場合はカテゴリ名から推定する。
- カテゴリからも決まらない場合は「知識の結晶」とする。
- 難易度は実作業時間と予定時間の長い方から決める。

報酬の最低値・上限・日次上限、タスク内容の誇張や不適切な入力への対処、報酬理由の表示、経済のインフレ対策は引き続き検討する。

報酬計算の重要な制約や最終的な上限は、可能な限りアプリ側でも検証する。

## 3. 作業時間とゲーム内進行

プレイヤーが現実のタスクや勉強に取り組んでいる時間に、ゲーム内施設とキャラクターの活動が進行する。

- 施設は通貨や育成素材などを生産する。
- キャラクターは指定された戦闘先で素材を収集する。
- 進行量は実際に取り組んだ時間や設定条件に基づいて決める。
- 通信切断やアプリを閉じた場合の扱いは今後定義する（中断・再開は上記のとおり）。

## 4. キャラクターの素材収集（戦闘）

- タスク設定時に、プレイヤーが戦闘先を選ぶ。
- 戦闘先ごとに入手できる素材と基本収集効率が異なる。
- キャラクターのレベルや強化状態により収集効率が上がる。
- キャラクター属性と戦闘先の相性によって効率倍率などの補正がかかる。
- 作業時間に応じて収集結果を算出する。

戦闘をプレイヤーが直接操作するか、自動進行にするかは未決定。

## 5. キャラクター育成

想定する要素：
- レベルアップ
- 素材収集・戦闘効率の向上
- 属性や戦闘先との相性を活かした編成
- 将来的な追加強化要素

育成で効率が上がる一方、現実で取り組む時間そのものの価値を損なわないように数値バランスを調整する。

## 6. 施設

施設は基本的にプレイヤーがタスクに取り組んでいる間だけ稼働する。

| 施設タイプ | 役割 |
|---|---|
| 通貨生成施設 | ゲーム内通貨を生成する |
| 育成素材生成施設 | キャラクターのレベルアップなどに使う素材を生成する |
| 合成施設 | 一部キャラクターへのプレゼントなどを合成する |
| その他 | 必要に応じて追加を検討する |

施設強化によって、生産量・効率・機能などが向上する想定。稼働条件、同時稼働数、保管上限などは未決定。

## 7. 拠点・シェアハウス

キャラクターたちが暮らす空間を表示し、家具や施設を設置・強化する。

想定機能：
- キャラクターが拠点で過ごす様子の表示
- 家具の購入・配置
- 施設の設置・強化
- キャラクターのレベル・育成状況の確認
- コスチュームの購入・変更
- キャラクターへのプレゼント
- 解禁した趣味時間やコンテンツの利用

## 8. ゲーム内経済・報酬の使い道

獲得した通貨や素材は、以下に使用する。
- キャラクターのコスチューム購入
- 施設の設置・強化
- 家具の購入
- プレゼントや合成素材の入手
- 趣味時間の解禁
- その他の育成・拠点発展要素

趣味時間の解禁はゲーム内にも何らかの作用をもたらす想定だが、具体的な効果は未確定。休息を罰や損失として扱わず、長期的に無理なく続けられる設計を重視する。

## 9. MVP で確認したい体験

最初の試作では、次の循環が成立するかを確認する。

1. タスクを登録してタイマーを開始できる。
2. 作業中にキャラクターの素材収集と施設生産が進む。
3. タスク完了後に報酬を受け取れる。
4. 報酬でキャラクターか施設を強化できる。
5. 強化によって次の作業で得られる成果が変化する。

この循環が楽しく、かつ負担にならないことを確認してから、拠点演出、交流、コスチューム、プレゼント合成などを拡張する。

## 10. 休憩と応援イベント

作業終了後、派遣していたキャラクターが休憩を提案する。プレイヤーは休憩時間を1〜60分の範囲で設定でき、休憩中はHUDに残り時間を表示する。休憩は報酬を減らさず、罰や損失として扱わない。

直前の作業終了から30分以内に休憩を完了せず次の作業を始めた場合は「連続作業」とみなし、キャラクターの応援イベントを表示する。連続作業が50分を超えた場合も、同じセッションにつき一度だけ応援する。応援イベントは報酬を付与せず、作業操作を妨げない。

推奨休憩時間、連続作業の判定時間、長時間作業のしきい値は `src/domain/constants.ts` の `BALANCE` で管理する仮値であり、仕様確定後に見直す。

## 11. 実装済みのタスク報酬・育成（MVP）

現時点の実装では、タスク完了時に既存の通貨・経験値報酬へ加えて、以下を付与する。

- 星屑: 実作業10分ごとに1個。端数は次回へ持ち越す
- 結晶: 難易度別の確率で1個。難易度は実作業時間と予定時間から決める。結晶タイプはユーザーキーワード、組み込みキーワード、カテゴリ既定タイプ、カテゴリ名推定の順で判定する
- キャラクター専用素材: 派遣した先頭キャラクターに対応する素材を確率で1個
- 同じタスクの再挑戦では結晶・素材を再抽選せず、星屑と通貨のみ加算する
- タスクで得た経験値が閾値に達すると自動でレベルアップする（複数レベル可、消費するのは経験値のみ。保存データ読込時・上限解放後の保留経験値も反映する）
- 硬貨・星屑を消費すれば、経験値が足りなくても手動で1レベル上げられる
- レベル上限解放は段階ごとに結晶・専用素材・硬貨を消費し、上限を20→30→40→50→60→70へ拡張する
- かけらと硬貨を合成すると、任意の種類・レアリティの結晶を1個作れる

結晶合成では、結晶タイプごとに使うかけらを固定する。

| 結晶 | 使うかけら |
|---|---|
| 知識・思考 | 月のかけら |
| 創造・努力 | 太陽のかけら |
| 探究 | 星のかけら |

| レアリティ | かけら | 硬貨 |
|---|---:|---:|
| N | 5 | 100 |
| R | 15 | 300 |
| SR | 30 | 800 |
| SSR | 60 | 2000 |
| UR | 120 | 5000 |

合成に失敗した場合はかけら・硬貨を消費しない。合成で得た結晶はドロップした結晶と同じく上限解放に使える。

抽選値と設定は `packages/core/src/rewards/` と `packages/core/src/progression/`、合成レシピは `packages/core/src/inventory/crystalSynthesis.ts` で管理する。

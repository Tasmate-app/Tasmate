# プロジェクト概要

## 1. コンセプト

現実世界での勉強・作業・タスクの完了や継続を、ゲーム内の報酬やキャラクターの成長につなげる、生活支援型の育成ゲームを開発する。

プレイヤーは自分でタスク、勉強予定、実施時間を設定して取り組む。行動に応じてゲーム内通貨や素材を獲得し、キャラクターの育成、拠点の発展、コスチュームや家具の購入などに使用する。

中心となる体験は「現実で頑張ることが、キャラクターたちの生活や成長につながる」こと。ゲームとしての楽しさを、現実のタスクを始めるきっかけや継続するモチベーションに結びつける。

## 2. 目指す体験

- **現実の行動とゲーム進行を連動させる：** タスクの完了、勉強時間、継続などをゲーム内の成果に反映する。
- **自分で計画を立てられる：** タスクの実施時間、勉強タイマー、勉強予定をプレイヤーが設定する。
- **行動内容に応じた報酬：** タスクや勉強科目などをもとに AI が報酬を決定する。
- **作業中にも世界が進む：** プレイヤーが作業している間、キャラクターが素材収集を行い、施設が稼働する。
- **成長の循環を作る：** 報酬をキャラクターや施設に投資し、次回以降の活動を効率化・魅力化する。
- **休息も尊重する：** 趣味時間の解禁などを含め、無理なく続けられる体験を目指す。

## 3. 主な画面

タブは **ホーム / 履歴 / 計画 / 拠点 / キャラクター / 施設 / かばん / ショップ / 合成** の9種類とする。分類管理は履歴画面から開く。

ナビゲーションはWeb・Nativeで共通のメタデータを使う。Webは768px未満でHUDのメニューボタンから開く左ドロワー、768px以上で常設の左サイドバーを表示する。常設時はサイドバーが画面全体の高さを占め、HUDは本文側の上に置く。表示項目と並び順は設定画面から変更でき、ホームは常に表示される。ブレークポイントは480 / 768 / 1024pxに統一し、本文はWebで最大1200px、Nativeではタブレットでも1カラム最大720pxに収める。

### ホームタブ（タスク管理・出撃）

現実で取り組むタスクや勉強を設定し、開始・進行・完了を管理する。ゲーム内の素材収集に向かうキャラクターと出撃先を選ぶ準備画面も兼ねる。画面は見出し、今週の進捗（達成率・曜日ごとの予定・連続週数）、次のクエスト、クエストボードの順で構成し、Web・Nativeで同じ並びにする。

### 履歴タブ

作業時間の集計・推移・カテゴリー別内訳とセッション一覧を確認する。終了済みセッションの削除と、分類管理への導線を持つ。

### 計画タブ

週間カレンダー、繰り返し予定、週間達成、連続達成ランク、報酬倍率、休息週、週次判定履歴を扱う。

### 拠点タブ（キャラクターのシェアハウス）

キャラクターたちが過ごす空間を眺め、施設や家具の配置状況を確認する。施設の強化・稼働切替は施設タブで行う。空間体験の参考として『ブルーアーカイブ』のカフェ、『リバース：1999』のウィルダネスを挙げる。具体的なUI・アート・演出は独自に設計する。

### キャラクタータブ

所持キャラクターの一覧とステータス、育成を行う。

### 施設タブ

施設の生産状況、強化、稼働切替を行う。

### かばんタブ

所持している素材と報酬履歴を確認する。

### ショップタブ

通貨を使った施設強化を購入する。家具・コスチュームは準備中。

### 合成タブ

かけらと硬貨から結晶を合成する。

## 4. 基本的なゲームループ

1. タスク・勉強内容、予定、実施時間を設定する。
2. 派遣するキャラクターと戦闘先を選ぶ。
3. 現実のタスクや勉強を開始する。
4. 取り組み中に施設が生産し、キャラクターが素材を収集する。
5. 完了・継続状況などをもとに AI が報酬を決定する。
6. 通貨・素材などを受け取る。
7. 報酬でキャラクターを育成し、施設を強化し、家具やコスチュームを入手する。
8. 成長した状態で次のタスクに取り組む。

## 5. 成功条件

- タスクや勉強を始めるきっかけになる。
- 現実の行動が納得感のある報酬につながる。
- キャラクターや拠点の成長が継続の楽しさを生む。
- 報酬のために無理をしたり、休息を避けたりする設計にならない。
- 予定どおりにできなかった日があっても再開しやすい。
- タスク管理としての実用性と、育成ゲームとしての楽しさを両立する。

## 6. 一文で表すと

**現実の勉強やタスクへの取り組みを、キャラクターの成長・素材収集・拠点発展へとつなげる、生活支援型の育成ゲーム。**

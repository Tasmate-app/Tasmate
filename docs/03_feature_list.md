# 機能一覧・実装優先度

## 優先度の定義

- **P0 — MVP 必須：** 基本ループを検証するために必要
- **P1 — 初期版以降：** 基本ループの後に追加
- **P2 — 将来候補：** 詳細設計やユーザー反応を見て検討

## MVP の推奨範囲

最初は次の機能に絞る。

1. タスク作成
2. 勉強・作業タイマー
3. タスク完了記録
4. AI または暫定ルールによる報酬決定
5. 戦闘先選択と作業時間に応じた素材収集
6. キャラクターの簡易レベルアップ
7. 通貨・素材を生成する基本施設を1〜2種類
8. 施設強化または家具購入
9. 進行結果・所持資源の表示
10. データ保存

## MVP の完了条件（案）

- タスクを登録し、タイマーを開始・停止できる。
- タイマー終了後に作業時間と完了状態を記録できる。
- 作業時間に応じて素材収集と施設生産の結果が反映される。
- 報酬を受け取り、キャラクターまたは施設を強化できる。
- アプリを再起動しても主要なデータが保持される。
- 中断や失敗があっても、データ破損や過度なペナルティが発生しない。

## 後回しにする機能

MVP では、複雑な戦闘操作、豊富なキャラクター交流、プレゼント合成、趣味時間の詳細効果、大規模な家具配置システムなどは必須にしない。

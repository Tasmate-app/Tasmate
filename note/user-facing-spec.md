## 1. アプリの全体像

### 1.1 コンセプト

現実の勉強・作業・運動・家事などの予定を「クエスト」として登録し、実際に取り組んだ時間をゲーム内の報酬と成長に変換する。

- 予定を立てる
- 出撃（作業タイマー）を開始する
- 完了または中断する
- 通貨・経験値・素材・星屑・結晶を獲得する
- 仲間を育てる
- 施設を強化する
- 作業履歴と週間達成を確認する

ゲーム要素は現実の作業を続けるための補助であり、タスク管理とタイマーの使いやすさが最優先される。

### 1.2 基本ループ

1. 出撃画面でクエストを追加する
2. クエストを選び、探索先と派遣する仲間を決める
3. 作業タイマーを開始する
4. 終わったら「完了して終了」または「中断して終了」を選ぶ
5. 報酬を確認する
6. 必要に応じて休憩を取る
7. キャラクターのレベルアップや施設強化を行う
8. 履歴と週間達成率を確認する

### 1.3 1日の利用例

- 朝: 今日やることをクエストとして登録する
- 作業前: クエストを選び、探索先と仲間を決めて出撃する
- 作業中: タイマーを確認する。必要なら一時停止する
- 作業後: 完了して報酬を受け取り、推奨時間の休憩を取る
- 夜: 履歴で作業時間を確認し、余った素材で仲間を育てる
- 週明け: 先週の達成率と連続達成週数を確認する

### 1.4 初期状態

アプリを初めて起動したときの状態は次のとおり。

| 項目 | 初期値 |
| --- | --- |
| 通貨（硬貨） | 100 |
| 星屑 | 0 |
| 太陽のかけら・月のかけら・星のかけら | 各0 |
| 所持キャラクター | ヒナタ（Lv.1）、ルナ（Lv.1） |
| 所持施設 | コイン工房（Lv.1、稼働中）、星屑ハウス（Lv.1、稼働中） |
| クエスト | なし |
| 作業履歴 | なし |
| 連続達成週数 | 0週 |
| 累計達成週数 | 0週 |
| 最高記録 | 0週 |
| 休憩週 | なし |

アステルはキャラクター定義としては存在するが、初期所持ではなく、入手手段も現時点では用意されていない。

### 1.5 用語

| 用語 | 意味 |
| --- | --- |
| クエスト | 現実で取り組む予定。タイトル、内容、分類、予定時間、予定日、時刻を持つ |
| 出撃 | クエストに対して作業タイマーを開始すること |
| 探索先 | 出撃時に選ぶ場所。属性相性と入手素材の比率が異なる |
| 仲間 | 出撃に派遣するキャラクター。複数選択できる |
| 収集効率 | 作業時間あたりの素材獲得量に影響する値 |
| 星屑 | 実作業時間に応じて貯まる育成素材 |
| 結晶 | タスク完了時に確率で入手するレアリティ付き素材。上限解放に使う |
| 合成 | かけらと硬貨を消費して、任意の結晶を作る操作 |
| キャラクター専用素材 | 特定キャラクターの上限解放にだけ使う素材 |
| 週間達成 | 1週間の完了率が80%以上になること |
| 休息週 | 達成判定を休み、連続達成週数を維持する週 |
| 応援イベント | キャラクターが作業や休憩に対して声をかける通知 |

## 2. 起動・保存・共通UI

### 2.1 起動時の表示

起動直後は読み込み画面が表示される。

- ロゴ「T」
- アプリ名「Tasmate」
- サブ表記「STUDY QUEST」
- 読み込み中のインジケーター
- メッセージ「ゲームデータを読み込んでいます…」

保存データの読み込みが終わるまで、タブ画面や操作可能なUIは表示されない。読み込み中にエラーが発生した場合は、読み込み画面にエラーメッセージが表示される。

### 2.2 保存と復元

- データは端末内に自動保存される。
- 操作のたびに即時保存されるわけではなく、短い待ち時間の後にまとめて保存される。
- アプリを閉じたりバックグラウンドへ移動したりすると、保留中の保存を急いで実行する。
- 次回起動時は保存データから状態が復元される。
- 作業中にアプリを閉じても、作業タイマーは開始時刻を基準に進み続ける。再度開くと、閉じていた時間も経過時間に含まれる。
- 一時停止中にアプリを閉じた場合は、一時停止した時点で時間が止まったまま復元される。
- 休憩中にアプリを閉じても休憩時間は進む。再起動時、既に設定時間を過ぎていれば休憩完了として扱われる。

### 2.3 保存データの異常時

- 保存先からの読み込み自体に失敗した場合、既存データを上書きしないように自動保存が停止する。
- 保存データの形式が壊れている場合は、エラーメッセージを表示したうえで初期状態で起動する。その後の操作で新しいデータが保存される可能性がある。
- 保存に失敗すると、タブ画面上部に「保存データの処理に失敗しました」というバナーと詳細メッセージが表示される。
- バナーは保存が成功するか、画面が再読み込みされるまで残ることがある。

### 2.4 HUD（画面上部の常時表示）

タブ画面では画面上部に所持状況が表示される。

| 表示 | 内容 |
| --- | --- |
| 通貨 | 現在の硬貨数 |
| 星屑 | 現在の星屑数 |
| 太陽のかけら | 現在の所持数 |
| 月のかけら | 現在の所持数 |
| 星のかけら | 現在の所持数 |

作業中・一時停止中・休憩中は、HUDにセッション状態が追加表示される。

- 状態: 作業中 / 一時停止中 / 休憩中
- 経過時間（休憩中は残り時間）
- 現在のクエスト名（作業中・一時停止中のみ）

### 2.5 タブバー

画面下部に6つのタブが並ぶ。

| 順序 | タブ名 | 補助名 | 内容 |
| --- | --- | --- | --- |
| 1 | 出撃 | クエスト | 今日の作戦、クエストボード、作業、報酬、週間計画 |
| 2 | 履歴 | 作業ログ | 作業時間の集計、分類別内訳、セッション一覧 |
| 3 | 拠点 | シェアハウス | 3D住居、住人、施設 |
| 4 | キャラ | 仲間 | キャラクターの状態、育成、上限解放、報酬履歴 |
| 5 | かばん | 所持品 | 通貨・星屑・結晶・素材の一覧 |
| 6 | 合成 | 結晶づくり | かけらと硬貨から結晶を作る |

出撃以外の項目は設定から表示・非表示と並び順を変更できる。

キーボード入力中はタブバーが隠れ、入力欄が隠れないようになっている。

### 2.6 応援トースト

キャラクターからの応援メッセージは、画面下部にトーストとして表示される。

- 表示されるメッセージは1件ずつ
- 閉じるボタンで消せる
- 閉じると「確認済み」として扱われる
- 複数のイベントが発生した場合は、新しいものから順に表示される

### 2.7 画面共通の操作

- モーダルは下からスライドして表示される。
- モーダルの背景をタップすると閉じる。
- 閉じるボタンには「閉じる」のアクセシビリティラベルが付いている。
- モーダル上部には英語の小見出し（例: COMMAND）が表示されることがある。

## 3. 出撃（ホーム）画面

### 3.1 画面の構成

上から順に次の要素が並ぶ。

1. 画面ヘッダー「出撃」
2. 連続達成週数のピル
3. 「今日の作戦」カード
4. 作業中パネル、または報酬結果・休憩パネル
5. 次のクエスト（存在する場合）
6. クエストボード
7. 週間計画の開閉ボタン
8. 週間計画（開いた場合）

### 3.2 今日の作戦

- 見出し「今日の作戦」
- 対象週の範囲（例: 11月10日 〜 11月16日）
- 今週の達成率
- 完了件数 / 対象件数
- 週間進捗バー
- 今日の予定件数
- 今日の完了件数
- 連続達成週数
- 月曜から日曜までの7日分の日付と、各日の完了数 / 予定数
- 今日の日付は強調表示される
- 「＋ クエストを追加」「⏱ 即時開始」「週間計画」の操作ボタン

### 3.3 状態に応じた表示

出撃画面の中央部分は、状態によって表示が切り替わる。

| 状態 | 表示 |
| --- | --- |
| 作業中または一時停止中 | 探索中パネル |
| 作業直後で報酬結果を閉じていない | クエスト完了パネル |
| 休憩中 | 休憩中パネル |
| 上記以外 | 何も表示されない、または次のクエスト |

報酬結果パネルは「クエスト一覧に戻る」を押すまで表示される。アプリを再起動した場合は報酬結果パネルは復元されないが、報酬自体は保存されている。

### 3.4 次のクエスト

未完了のクエストがある場合、「NEXT MISSION」として1件表示される。

- クエスト名
- 予定日
- 予定時刻
- 予定時間（ストップウォッチの場合は「ストップウォッチ」）
- 「出撃準備」ボタン（ストップウォッチの場合は「計測開始」）

### 3.5 クエストボード

- 見出し「クエストボード」
- 開始可能なクエスト数
- 「出撃可能」バッジ
- 未完了のクエスト一覧
- 「＋ 追加」ボタン
- 「⏱ 即時開始」ボタン（ストップウォッチ）

クエストカードには次が表示される。

- クエスト名
- 分類名
- 予定日
- 予定時刻
- 予定時間（ストップウォッチの場合は「予定時間なし」）
- 内容・メモ
- 「今日」バッジ（予定日が今日の場合）
- 「期限超過」バッジ（予定日が今日より前の場合）
- カード本体をタップすると編集
- 出撃ボタンで出撃準備

クエストがない場合は「開始できるクエストがありません。新しいクエストを作成してください。」と表示される。

### 3.6 週間計画の開閉

- 「週間計画」ボタン、または画面下部の開閉領域で表示を切り替える。
- 開いている間はボタンが「計画を閉じる」に変わる。

## 4. クエストの作成・編集・削除

### 4.1 新規作成

「＋ クエストを追加」またはクエストボードの「＋ 追加」から開く。モーダル名は「新しいクエスト」。

入力項目は次のとおり。

| 項目 | 必須 | 内容 |
| --- | --- | --- |
| クエスト名 | 必須 | 最大100文字。前後の空白は削除される |
| 内容・メモ | 任意 | 最大500文字 |
| カテゴリー | 任意 | 初期表示は先頭の有効なカテゴリー |
| サブカテゴリー | 任意 | 選択したカテゴリーに属するものだけ表示。初期値は「未分類」 |
| 計測方式 | 必須 | 「予定時間」または「ストップウォッチ」。初期値は「予定時間」 |
| 予定時間（分） | 予定時間のみ必須 | 1〜480分。初期値は25分 |
| 予定日 | 任意 | YYYY-MM-DD。初期値は今日。空欄なら日付なし |
| 開始時刻 | 任意 | HH:mm。終了時刻とセットで入力 |
| 終了時刻 | 任意 | HH:mm。開始時刻より後であること |

計測方式を「ストップウォッチ」にすると、予定時間の入力欄は表示されず、終了時の実作業時間を記録する。ストップウォッチでも予定日・開始時刻・終了時刻は任意で設定でき、繰り返し予定には設定できない。

予定日の下には「今日」「明日」「2日後」「1週間後」のショートカットがある。選択中の日付は強調される。

### 4.2 入力エラー

保存時に次の場合はエラー文が表示され、保存されない。

- クエスト名が空: 「クエスト名を入力してください。」
- 予定時間が範囲外: 「予定時間は1〜480分の範囲で入力してください。」（ストップウォッチでは不要）
- 日付の形式が不正: 「日付は YYYY-MM-DD 形式で入力してください。」
- 開始時刻だけ、または終了時刻だけ入力: 「開始時刻と終了時刻は両方入力してください。」
- 時刻の形式が不正: 「開始時刻は HH:mm 形式で入力してください。」など
- 終了時刻が開始時刻以前: 「終了時刻は開始時刻より後にしてください。」
- 時刻を入力したが日付が空: 「時刻を設定する場合は日付も入力してください。」

日付として存在しない値（例: 2026-02-30）は不正として扱われる。

### 4.3 編集

クエストカード、クエストボード、週間計画の予定をタップすると「クエストを編集」が開く。

- 既存の値が初期表示される。
- 保存すると内容が更新される。
- 予定日を変更しても、すでに作業中のセッションには影響しない。
- 計測方式を変更すると、予定時間またはストップウォッチの設定に切り替わる。ストップウォッチから予定時間へ戻す場合は予定時間を再入力する。
- 完了済みのクエストも編集できるが、再度の出撃対象にはならない。
- 進行中のクエストは出撃中パネルから操作する。

### 4.4 削除

編集モーダル下部の「この予定を削除」から削除する。

- 確認ダイアログ「予定を削除」「「クエスト名」を削除しますか？」が表示される。
- 「削除」を選ぶとクエスト一覧から消える。
- 削除は記録を消すのではなく「アーカイブ」として扱われる。
- 過去の作業履歴や週間判定の分母は原則として残る。
- 週の途中で作成し、同じ週のうちに削除した未完了クエストは、週間判定の分母から除外される。
- 削除したクエストを元に戻す操作は現時点では用意されていない。

### 4.5 カテゴリー選択の挙動

- カテゴリーは横並びの選択肢から1つ選ぶ。
- カテゴリーを変更すると、サブカテゴリーは「未分類」に戻る。
- サブカテゴリーは任意。選択したカテゴリーに属するものだけが表示される。
- 現在のカテゴリーが削除済みの場合、その値だけは選択肢に「（削除済み）」として残る。既存の予定の分類が勝手に変わらないようにするため。
- 現在のサブカテゴリーが削除済みの場合も同様に残る。
- 有効なカテゴリーが1件もない場合は「カテゴリーがありません。分類画面から追加してください。」と表示される。

### 4.6 未完了クエストの状態

クエストの状態は画面や一覧で次のように表示される。

| 状態 | 表示 |
| --- | --- |
| 予定 | 予定 |
| 出撃中 | 進行中 |
| 完了 | 完了 |
| 取消 | 取消（通常操作では発生しない） |

### 4.7 ストップウォッチ即時開始

予定を先に作らず、今から作業を始めたいときに使う。出撃画面の「⏱ 即時開始」、またはクエストボードの「ストップウォッチで開始」から開く。

入力項目は次のとおり。

| 項目 | 必須 | 内容 |
| --- | --- | --- |
| クエスト名 | 必須 | 最大100文字 |
| 内容・メモ | 任意 | 最大500文字 |
| カテゴリー | 任意 | 通常のクエストと同じ |
| 探索先 | 必須 | 3か所から1つ |
| 派遣する仲間 | 必須 | 1人以上 |

- 予定時間・予定日・時刻は入力しない。
- 開始するとクエストが作成され、そのまま計測が始まる。
- 予定時間は 0（予定時間なし）として扱い、進捗バーと進捗率は表示しない。
- 予定日を持たないため、週間計画・カレンダー・週次判定の対象にはならない。
- 作業履歴と報酬には通常のクエストと同じように記録される。
- 進行中の作業がある場合は開始できない。

即時開始とは別に、4.1 の計測方式で「ストップウォッチ」を選ぶと、予定日時を持つストップウォッチ形式のクエストを作成できる。この場合は予定日時から出撃準備を開いて計測を開始する。

## 5. 週間計画とカレンダー

### 5.1 週間の継続状況パネル

週間計画を開くと、最初に「週間の継続状況」が表示される。

- 現在のランク名（例: ルーキー）
- 報酬倍率（例: ×1.00）
- 連続達成週数
- 最高記録
- 累計達成週数
- 次のランクまでの残り週数
- ランク進捗バー
- 注意書き「未達でも連続週数が1つ減るだけです。累計達成週数と最高記録は失われません。」
- 表示中の週を休憩週にする / 解除するボタン
- 来週を休憩週にする / 解除するボタン

### 5.2 週間スケジュール

- 見出し「週間スケジュール」
- 前週ボタン、今週ボタン、翌週ボタン
- 週の範囲（例: 11月10日 〜 11月16日）
- 今週を表示している場合は「今週」バッジ
- 完了件数 / 対象件数
- 週間達成率
- 進捗バー
- 状態に応じた案内文

案内文の例:

- 休憩週: 「この週は休憩週です。連続週数は維持されますが、達成には数えません。」
- 予定なし: 「この週の予定はまだありません。」
- 80%到達済み: 「80%に到達しています。このまま完了数を維持しましょう。」
- 未到達: 「あと N 件完了すると週間達成です（80%基準）。」

### 5.3 曜日ごとの表示

- 月曜から日曜までの7日分を横に並べる。
- 各日に曜日、日付、完了数 / 予定数を表示する。
- 今日の日付は強調される。
- 日付をタップすると、その日の予定一覧が下に表示される。

### 5.4 選択した日の予定

- 選択中の日付（例: 2026/11/10）
- 予定件数と完了件数
- 「この日に追加」ボタン（その日付を初期値にして新規クエスト作成）
- 予定一覧

予定一覧は開始時刻の早い順に並び、時刻未設定の予定は末尾に表示される。各行には次が表示される。

- 分類色の縦線
- クエスト名
- 時刻、分類名、予定時間
- 状態バッジ（予定 / 進行中 / 完了 / 取消）

予定をタップすると編集できる。予定がない場合は「この日の予定はありません。予定を追加して週間達成を目指しましょう。」と表示される。

### 5.5 直近の週次判定

- 直近の判定結果（週間達成 / 未達成 / 休息週 / 判定保留）
- 対象週の範囲
- 達成率
- 連続達成週数の変化（例: 2→3週）
- 今週の進捗

まだ判定がない場合は「週が終わると、ここに達成状況とランクの変化が記録されます。」と表示される。

### 5.6 繰り返し予定

同じパネル内に「繰り返し予定」の一覧と「追加」ボタンがある。詳細は次章。

## 6. 繰り返し予定

### 6.1 作成

「繰り返し予定」の「追加」から開く。モーダル名は「繰り返し予定を追加」。

| 項目 | 必須 | 内容 |
| --- | --- | --- |
| 予定名 | 必須 | 最大100文字 |
| 内容・メモ | 任意 | 最大500文字 |
| 予定時間（分） | 必須 | 1〜480分。初期値は25分 |
| 繰り返す曜日 | 必須 | 月〜日から1つ以上。初期値は月曜 |
| 開始時刻 | 任意 | HH:mm。終了時刻とセット |
| 終了時刻 | 任意 | HH:mm。開始時刻より後 |
| 開始日 | 必須 | この日以降に予定を生成する。初期値は今日 |
| 終了日 | 任意 | この日まで予定を生成する |

### 6.2 入力エラー

- 予定名が空
- 予定時間が1〜480分の範囲外
- 曜日が未選択
- 開始時刻と終了時刻の片方だけ入力
- 時刻の形式が不正
- 終了時刻が開始時刻以前
- 開始日・終了日の形式が不正
- 開始日より終了日が前

### 6.3 予定の自動生成

- 登録すると、開始日を含む週の該当曜日に予定が作成される。
- 週間計画で別の週を開くと、その週の分が自動生成される。
- アプリ起動中は定期的に、その週の予定が不足していれば生成される。
- 週次判定のタイミングでも、対象週の予定が生成される。
- 生成される予定には、繰り返し設定のタイトル・内容・分類・予定時間・時刻が反映される。
- 同じルールの同じ日付の予定が重複して作られることはない。
- 一度削除した回の予定は、同じルールを再生成しても復活しない。

### 6.4 個別の予定を編集した場合

- 繰り返しから生成された予定も、通常のクエストと同じように編集できる。
- 予定日を変更した場合、その予定は「元の日付の回」として扱われる。
- 後から繰り返しルールを変更しても、日付を移動した予定や完了済みの予定は上書きされない。
- 個別に削除した予定は、その回だけ削除される。

### 6.5 ルールの変更

- 「繰り返し予定を編集」から変更できる。
- 変更内容は、今後生成される未完了の予定に反映される。
- 完了済みの予定、日付を移動した予定、個別に削除した予定は原則として保持される。
- 曜日を外した場合、その曜日の今後の未完了予定はアーカイブされる。
- 外した曜日を再び追加した場合、ルール変更によってアーカイブされた予定は復元されうる。ただしユーザーが個別に削除した予定は復元されない。

### 6.6 ルールの削除

- 「この繰り返しを削除」から削除する。
- 確認ダイアログが表示される。
- 削除すると、そのルールの今後の未完了予定はアーカイブされる。
- 過去の予定、完了済みの予定、作業履歴は残る。

### 6.7 一覧表示

一覧には次が表示される。

- 予定名
- 繰り返す曜日（例: 月・水・金）
- 開始時刻と終了時刻（未設定なら「時間未設定」）
- 「編集」ラベル

## 7. 出撃準備

クエストの出撃ボタン、または「次のクエスト」の「出撃準備」から開く。モーダル名は「出撃準備」、サブタイトルはクエスト名。

### 7.1 サマリー

| 表示 | 内容 |
| --- | --- |
| 予定時間 | クエストの予定時間。ストップウォッチの場合は「ストップウォッチ」 |
| 編成人数 | 選択中の仲間の数 |
| 収集効率 | 選択中の仲間の効率の合計（小数第1位） |

### 7.2 探索先の選択

3か所から1つ選ぶ。初期選択は「朝日の丘」。

| 探索先 | 説明 | 入手素材の比率 | 基本効率 | 推奨属性 |
| --- | --- | --- | --- | --- |
| 朝日の丘 | 太陽のかけらが眠る初心者向けの丘 | 太陽70% / 星30% | 1.0 | 太陽 |
| 月夜の遺跡 | 月のかけらが見つかる静かな遺跡 | 月70% / 星30% | 1.1 | 月 |
| 星降る原野 | 星のかけらが舞う広大な原野 | 星60% / 太陽20% / 月20% | 1.2 | 星 |

各探索先カードには名前、説明、素材比率が表示される。

### 7.3 仲間の選択

- 所持しているキャラクターが一覧表示される。
- タップで選択 / 解除を切り替える。
- 初期状態では先頭のキャラクター1人だけが選択されている。
- 複数選択できる。上限はない。
- 各キャラクターには次が表示される。
  - 名前
  - レベル
  - 現在の効率
  - 探索先と属性が一致する場合は「相性ボーナス」
  - 次のレベルまでの経験値バー
- 0人では出撃できない。

### 7.4 効率の考え方

キャラクターの効率は次の要素で決まる。

1. キャラクターの基本効率
2. レベルによる上昇
3. 探索先と属性の一致によるボーナス
4. 探索先自体の基本効率

目安:

- ヒナタ: 基本効率1.0、太陽属性
- ルナ: 基本効率1.2、月属性
- アステル: 基本効率0.9、星属性

属性一致時は効率が1.5倍になる。レベルが1上がるごとに効率が0.1ずつ上がる。

### 7.5 出撃開始

- 仲間を1人以上選ぶとボタンが「出撃して作業開始」になる。ストップウォッチの場合は「計測を開始」。
- 0人の場合は「仲間を選んでください」と表示され、押せない。
- 開始するとクエストの状態が「進行中」になり、出撃画面に探索中パネルが表示される。ストップウォッチの場合はその場で計測が始まる。
- 進行中の休憩がある場合は、その休憩を切り上げたものとして扱われる。
- 同時に進行できる作業は1件だけ。別のクエストを開始するには、現在の作業を終了する必要がある。

## 8. 作業中の画面とタイマー

### 8.1 探索中パネル

見出しは「探索中」。表示内容は次のとおり。

- 「作業中」または「一時停止中」バッジ
- クエスト名
- 経過時間
- 予定時間と進捗率（ストップウォッチでは予定時間なしの表示のみ）
- 稼働中の施設数
- 探索先
- 素材の入手候補と比率
- 操作ボタン

### 8.2 時間表示

- 1時間未満は「分:秒」
- 1時間以上は「時間:分:秒」
- 予定時間を超えてもタイマーは止まらない
- 進捗率は100%で止めて表示される
- ストップウォッチでは予定時間・進捗率を表示せず、経過時間だけを表示する

### 8.3 操作

| ボタン | 動作 |
| --- | --- |
| 一時停止 | タイマーを止める。一時停止中の時間は作業時間に含まれない |
| 再開 | 一時停止を解除し、止めていた時間を除いて再開する |
| 完了して終了 | 完了扱いで終了し、報酬を確定する |
| 中断して終了 | 中断扱いで終了し、報酬を確定する。クエストは「予定」に戻る |
| 記録せず取消 | 確認後、作業記録も報酬も残さずに終了する。クエストは「予定」に戻る |

### 8.4 一時停止の扱い

- 一時停止を押した時点で経過時間が止まる。
- 一時停止中の時間は、経過時間、報酬、履歴、施設生産のすべてに含まれない。
- 一時停止中にアプリを閉じても、止まった時点の時間で復元される。
- 再開すると、停止していた時間を差し引いた状態で再開する。

### 8.5 アプリを閉じた場合

- 作業中の状態でアプリを閉じても、タイマーは進み続ける。
- 再度開くと、閉じていた時間も含めた経過時間になる。
- 端末の時計が大きく変更された場合、経過時間が想定と変わることがある。

### 8.6 同時進行と制約

- 作業中に別のクエストを開始することはできない。
- 作業中に休憩を開始する操作はない。休憩は作業終了後に案内される。
- 作業中にクエストを削除しても、進行中のセッションは終了するまで残る。
- 作業中のクエストは編集できるが、選択した探索先や仲間はセッション開始時の内容で固定される。

### 8.7 取消の確認

「記録せず取消」を押すと、確認ダイアログが表示される。

- タイトル: 「出撃を取り消す」
- 本文: 「作業記録と報酬は保存されません。取り消しますか？」

取消した場合、作業履歴、報酬、経験値、素材、星屑は一切増えない。

## 9. 完了・中断・取消と報酬

### 9.1 結果ごとの違い

| 結果 | クエスト状態 | 履歴 | 報酬 | 結晶・専用素材の抽選率 | 星屑 |
| --- | --- | --- | --- | --- | --- |
| 完了して終了 | 完了 | 残る | 通常 | 通常 | 実作業時間分 |
| 中断して終了 | 予定に戻る | 残る | 通常の50% | 通常の50% | 実作業時間分 |
| 記録せず取消 | 予定に戻る | 残らない | なし | なし | なし |

中断時も通貨・経験値・素材・星屑は0にはならない。再開しやすさを優先し、50%の報酬が残る。

### 9.2 報酬結果パネル

完了または中断すると「クエスト完了」パネルが表示される。

- 「MISSION COMPLETE」
- 「報酬を獲得しました」
- 通貨
- 経験値
- 素材（太陽・月・星のかけら）
- 星屑
- ドロップした結晶
- ドロップしたキャラクター専用素材
- 判定方法（キーワード判定）
- 難易度
- 結晶・素材が出なかった場合は「結晶・素材なし」
- 入力概要（クエスト名 / 作業時間 / 完了または中断 / 探索先）
- 週間継続倍率が1より大きい場合、その倍率

パネル下部には休憩の案内が表示される。「クエスト一覧に戻る」で閉じる。

### 9.3 通貨

通貨は次の合計で決まる。

- 作業時間分の基本報酬
- 稼働中のコイン工房の生産分

計算の目安:

- 基本: 実作業1分あたり10通貨
- コイン工房: 施設の生産量 × 実作業時間
- 中断時: それぞれ0.5倍
- 1セッションの上限: 3000通貨
- 端数は切り捨て

例: 25分作業、コイン工房Lv.1（5通貨/分）の場合

- 基本: 25 × 10 = 250
- 施設: 25 × 5 = 125
- 合計: 375通貨

### 9.4 経験値

- 実作業1分あたり5経験値
- 中断時は0.5倍
- 端数は切り捨て
- 派遣したキャラクター全員が同じ経験値を得る
- 閾値に達すると自動でレベルアップし、必要経験値を消費する（余剰は持ち越し、複数レベル可）
- 例: 25分作業なら125経験値

### 9.5 素材（太陽・月・星のかけら）

素材は「探索による収集」と「施設生産」の合計。

- 収集の基本量: 実作業1分あたり0.5 × 収集効率
- 探索先の比率に応じて、太陽・月・星に分配される
- 星屑ハウスは星のかけらを生産する
- 生産は作業中のみ行われ、停止中の施設は生産しない
- 中断時は収集・生産の両方に0.5倍
- 1セッションにつき、素材は種類ごとに最大60個
- 端数は切り捨て

例: 25分、ヒナタ1人、朝日の丘（相性一致）の場合

- ヒナタの効率: 1.0 × 1.5 = 1.5
- 収集量: 25 × 0.5 × 1.5 = 18.75
- 太陽: 18.75 × 0.7 = 13.125 → 13
- 星: 18.75 × 0.3 = 5.625 → 5
- 星屑ハウスLv.1の生産: 25 × 0.4 = 10
- 最終的な星のかけら: 5 + 10 = 15

### 9.6 星屑

- 実作業10分ごとに1個
- 端数は次回の作業に持ち越す
- 完了でも中断でも、実作業時間分は同じように貯まる
- 取消では増えない
- 例: 25分作業で2個獲得、5分は持ち越し
- 持ち越しは常に10分未満（10分になった時点で1個に変換）

### 9.7 結晶

- タスク完了時に30%の確率で1個
- 中断時は15%の確率
- 1回の報酬で最大1個
- 同じタスクでは再抽選されない。2回目以降の完了では結晶は出ない
- レアリティはタスクの難易度によって変わる
- 結晶の種類はタスク内容から判定される

難易度ごとのレアリティ抽選:

| 難易度 | N | R | SR | SSR | UR |
| --- | --- | --- | --- | --- | --- |
| 1 | 70% | 25% | 5% | - | - |
| 2 | 50% | 30% | 15% | 5% | - |
| 3 | 30% | 35% | 22% | 10% | 3% |
| 4 | 15% | 30% | 30% | 20% | 5% |
| 5 | 5% | 20% | 32% | 30% | 13% |

結晶の種類:

| 種類 | 主な内容の例 |
| --- | --- |
| 知識の結晶 | 勉強、学習、暗記、読書 |
| 思考の結晶 | 計算、数学、論理、プログラミング |
| 創造の結晶 | 作成、制作、レポート、デザイン |
| 探究の結晶 | 調査、研究、実験 |
| 努力の結晶 | 筋トレ、運動、練習、掃除 |

判定に迷う場合は、カテゴリーやキーワードから自動的に選ばれる。

### 9.8 結晶の合成

集めたかけらと硬貨を合成すると、任意の種類・レアリティの結晶を1個作れる。合成は「合成」画面で行う。

| 結晶 | 使うかけら |
| --- | --- |
| 知識の結晶 | 月のかけら |
| 思考の結晶 | 月のかけら |
| 創造の結晶 | 太陽のかけら |
| 探究の結晶 | 星のかけら |
| 努力の結晶 | 太陽のかけら |

| レアリティ | かけら | 硬貨 |
| --- | ---: | ---: |
| N | 5 | 100 |
| R | 15 | 300 |
| SR | 30 | 800 |
| SSR | 60 | 2000 |
| UR | 120 | 5000 |

- 合成に成功すると、選んだ結晶を1個獲得する
- かけらまたは硬貨が足りない場合は合成できず、素材は消費されない
- 合成で得た結晶は、ドロップした結晶と同じくレベル上限解放に使える
- 合成した結晶も所持数として保存される

### 9.9 キャラクター専用素材

- タスク完了時に40%の確率で1個
- 中断時は20%の確率
- 1回の報酬で最大1個
- 同じタスクでは再抽選されない
- 付与先は、そのセッションで最初に選択したキャラクター
- キャラクターごとに2種類の専用素材があり、どちらかが選ばれる

| キャラクター | 素材1 | 素材2 |
| --- | --- | --- |
| ヒナタ | 古代の羽根 | 生命の種 |
| ルナ | 魔力の花 | 神秘のインク |
| アステル | 魔導歯車 | 魔獣の爪 |

### 9.10 難易度の決まり方

タスク内容はキーワード判定で評価する。

- 実際の作業時間と予定時間のうち、長い方を基準にする
- 15分未満: 難易度1
- 30分未満: 難易度2
- 60分未満: 難易度3
- 120分未満: 難易度4
- 120分以上、または「大量」「長時間」「集中」などの強い表現を含む場合: 難易度5

結果画面の「判定」は「キーワード判定」と表示される。

### 9.11 週間継続倍率

- 連続達成週数に応じて、完了時の報酬に倍率がかかる。
- 対象は通貨・素材・経験値。
- 中断時にはかからない。
- 星屑、結晶、キャラクター専用素材にはかからない。
- 倍率適用後の通貨・素材にも上限（通貨3000、素材60/種）がかかる。

### 9.12 60秒未満の作業

- 実作業が60秒未満の場合、時間に応じた通貨・経験値・素材収集・施設生産・星屑は0になる。
- 完了扱いにした場合でも、結晶・専用素材の抽選は行われる可能性がある。
- 作業履歴には「1分未満」として残る場合がある。

### 9.13 同じクエストを再度作業した場合

- 通貨・経験値・素材・星屑は、作業するたびに獲得できる。
- 結晶とキャラクター専用素材は、同じクエストでは最初の1回しか抽選されない。
- 一度中断し、同じクエストを再開して完了した場合、最初の中断時に抽選済みなら結晶・専用素材は出ない。

### 9.14 二重付与の防止

同じセッションで「完了」を複数回確定することはできない。報酬は1セッションにつき1回だけ付与される。

## 10. 休憩

### 10.1 休憩の案内

作業終了後の報酬パネルに、推奨休憩時間が表示される。

| 実作業時間 | 推奨休憩 |
| --- | --- |
| 90分以上 | 20分 |
| 50分以上90分未満 | 15分 |
| 25分以上50分未満 | 10分 |
| 25分未満 | 5分 |

表示例: 「作業 25分 に対して、10分の休憩がおすすめです。」

### 10.2 休憩の開始

- プリセットは5分、10分、15分、20分、30分。
- 推奨時間のボタンは強調表示される。
- 休憩を開始すると「休憩中」パネルに切り替わる。

### 10.3 休憩中の表示

- 「休憩中」バッジ
- 残り時間
- 進捗バー
- 自動で完了することの案内
- 「休憩を終える」ボタン

報酬パネル内で休憩している場合は、設定した休憩時間も表示される。

休憩は自動で完了する。早めに終えたい場合は「休憩を終える」を押す。早終了した場合は、休憩完了の応援イベントは発生しない。

### 10.4 休憩完了

- 設定時間に達すると自動的に休憩完了になる。
- キャラクターから「休憩おつかれさま！…」の応援イベントが発生する。
- 報酬パネル側では「休憩完了」「おつかれさまでした。次のクエストもマイペースに進めましょう。」と表示される。

### 10.5 休憩と次の作業

- 休憩中に次の作業を開始すると、休憩は切り上げられる。
- 前回の作業終了から30分以内に、休憩を完了せず次の作業を始めると「連続作業」とみなされ、応援イベントが発生する。
- 休憩時間は1〜60分の範囲で扱われるが、画面のプリセットは上記5種類。

## 11. 週次判定・連続達成・休息週

### 11.1 週の区切り

- 週は月曜00:00に始まり、日曜23:59:59に終わる。
- 日付は端末のローカル時間で扱う。
- 週の対象は予定日で決まる。
- 予定日がないクエストは週次判定の対象外。

### 11.2 対象になるクエスト

- その週の予定日を持つクエスト（完了済みを含む）
- 予定日を持たないストップウォッチのクエストは対象外
- 未完了で削除されたクエストは、以下を除いて対象に残る
- その週の途中で作成され、その週のうちに削除された未完了クエストは対象外

これにより、週の途中で予定を作ってすぐ消すことで達成率を上げる行為を防いでいる。一方、前からあった予定を削除しても分母からは消えない。

### 11.3 達成条件

- 達成率80%以上で「週間達成」
- 必要完了数は切り上げ
- 対象0件の週は「判定保留」
- 休憩週に設定した週は「休息週」
- それ以外は「未達成」

例:

| 対象件数 | 必要な完了数 |
| --- | --- |
| 1件 | 1件 |
| 2件 | 2件 |
| 3件 | 3件 |
| 4件 | 4件 |
| 5件 | 4件 |
| 10件 | 8件 |
| 12件 | 10件 |

### 11.4 連続達成週数の変化

| 判定 | 連続達成週数 |
| --- | --- |
| 週間達成 | 1増える |
| 未達成 | 1減る（0未満にはならない） |
| 判定保留 | 変わらない |
| 休息週 | 変わらない |

- 未達成でも累計達成週数と最高記録は減らない。
- 累計達成週数は「週間達成」になった週だけ増える。
- 最高記録はこれまでの連続達成週数の最大値。

### 11.5 ランクと報酬倍率

| 連続達成週数 | ランク | 報酬倍率 |
| --- | --- | --- |
| 0〜1週 | ルーキー | ×1.00 |
| 2週 | トラッカー | ×1.10 |
| 3週 | レンジャー | ×1.20 |
| 4週 | キャプテン | ×1.30 |
| 5週 | エース | ×1.40 |
| 6週 | マスター | ×1.50 |
| 7週 | グランドマスター | ×1.60 |
| 8週以上 | レジェンド | ×1.75 |

### 11.6 休憩週

- 今週、来週、または表示中の未来の週を休憩週にできる。
- 判定済みの週は変更できない。
- 過去の週は休憩週にできない。
- 休憩週は連続2週まで。
- 休憩週は連続達成週数を維持するが、達成には数えない。
- 休憩週の判定結果は「休息週」と表示される。

設定できない場合は「休憩週を設定できません。連続利用の上限、または判定済みの週です。」と表示される。

### 11.7 判定のタイミング

- アプリ起動中は定期的に未判定の過去週を判定する。
- アプリが前面に戻ったときにも判定する。
- 長期間開かなかった場合も、さかのぼれる範囲で未判定週を順に判定する。
- 同じ週を二重に判定することはない。
- 判定結果は履歴として残る。

### 11.8 週次判定と休憩週の注意

- 週の途中で休憩週に設定した場合、その週の終了後に「休息週」として記録される。
- 休憩週に設定した週の予定は、通常どおり出撃・完了できる。予定が消えるわけではない。
- 休憩週を解除した場合、通常の達成判定に戻る。ただし判定済みの週は変更できない。

## 12. 履歴

### 12.1 集計の前提

- 終了した作業セッションだけが対象。
- 完了と中断の両方が含まれる。
- 取消したセッションは含まれない。
- 一時停止中の時間は含まれない。
- 作業日は、そのセッションを最初に開始した日付で扱う。日をまたいでも開始日側にまとめられる。
- 削除済みの分類は、履歴がある場合や絞り込みで選択している場合に「（削除済み）」と表示される。
- 時間表示は「2時間15分」「45分」「1分未満」「0分」の形式。

### 12.2 画面上部の合計

| 表示 | 内容 |
| --- | --- |
| 今日 | 今日の実作業時間 |
| 今週 | 今週の実作業時間 |
| 今月 | 今月の実作業時間 |
| 累計 | これまでの実作業時間 |

これらの合計は、下のカテゴリーフィルターの影響を受けない。

### 12.3 作業時間の推移

- 日 / 週 / 月 / 年 の表示切り替え
- 日: 直近7日
- 週: 直近8週
- 月: 直近6か月
- 年: 直近5年
- 各期間の作業時間を棒グラフで表示
- 棒が0の期間も表示される
- フィルター適用中の履歴がない場合は「この条件の作業履歴はまだありません。」と表示

### 12.4 カテゴリー別

- 「すべて」または各カテゴリーで絞り込む
- 削除済みカテゴリーは「（削除済み）」と表示される

- 作業時間の長い順に並ぶ
- カテゴリーを選択すると、サブカテゴリーの絞り込みが表示される

### 12.5 サブカテゴリー別

- カテゴリーを選択したときだけ表示される
- 「すべて」または各サブカテゴリーで絞り込む
- サブカテゴリーがない作業は「未分類」としてまとまる
- 削除済みサブカテゴリーは「（削除済み）」と表示される

### 12.6 作業セッション一覧

- 見出し「作業セッション（N件）」
- 最新100件まで表示
- 各行の内容
  - クエスト名（開始時点のタイトル）
  - 開始日時
  - カテゴリー / サブカテゴリー
  - 作業時間
  - 「完了」または「中断」バッジ
- カテゴリー名やサブカテゴリー名は、作業開始時点の名前で表示される
- カテゴリーを後から改名しても、過去の履歴の表示名は変わらない
- 削除済みの分類は「（削除済み）」のように表示されることがある

### 12.7 分類管理への移動

画面右上の「分類管理」からカテゴリー管理画面へ移動する。

## 13. カテゴリー管理

### 13.1 画面の目的

作業の分類を整理する。削除しても過去の履歴は残る。

### 13.2 カテゴリーの追加

- 見出し「カテゴリーを追加」
- カテゴリー名を入力
- 最大40文字
- 空欄は追加できない
- 有効なカテゴリーと同名のものは追加できない

### 13.3 カテゴリーの編集

各カテゴリーカードで次の操作ができる。

- 上へ移動
- 下へ移動
- 名前変更
- 削除

名前変更では「保存」「取消」が表示される。空欄や重複名は保存できない。

並び順は、クエスト作成時のカテゴリー選択肢の順序にも反映される。

### 13.4 カテゴリーの削除

- 確認ダイアログが表示される。
- 削除すると、そのカテゴリーと属するサブカテゴリーが「削除済み」になる。
- 過去の履歴は残る。
- 新しいクエストの選択肢には表示されない。
- 既にそのカテゴリーを使っているクエストを編集する場合、現在値として「（削除済み）」が選択肢に残る。
- 削除済みカテゴリーを元に戻す操作は現時点では用意されていない。
- 削除済みカテゴリーは画面下部の「削除済みカテゴリー」に表示される。

### 13.5 サブカテゴリー

各カテゴリーの下でサブカテゴリーを管理できる。

- 追加
- 名前変更
- 上へ移動
- 下へ移動
- 削除

- サブカテゴリー名は最大40文字。
- 同じカテゴリー内で同名のものは追加できない。
- 空欄は追加できない。
- 削除すると新しいクエストの選択肢から消える。
- 既に使われている場合は、現在値として「（削除済み）」が残る。
- 過去の履歴は残る。

| その他 | なし |

## 14. キャラクター

### 14.1 画面の構成

- 画面上部で所持キャラクターを切り替える
- 選択中のキャラクターのカード
- 属性、レベル、基礎効率、説明
- 「ステータス」「育成」「履歴」のタブ

### 14.2 キャラクターカード

- 名前
- 属性（太陽 / 月 / 星）
- レベル
- 「出撃可能」バッジ
- 説明文
- 基礎効率

### 14.3 ステータスタブ

- レベル
- 所持経験値
- 次のレベルまでに必要な経験値
- 基本効率
- レベル補正
- 探索先と属性が一致した場合の補正

レベル補正は「1 + (レベル - 1) × 0.1」で計算される。属性一致時はさらに1.5倍。

### 14.4 育成タブ

表示内容:

- 経験値と次のレベルまでのバー
- レベルアップ費用（硬貨と星屑）
- 所持通貨
- レベル上限
- 上限解放段階
- レベルアップ後の効率
- レベルアップボタン
- 上限解放の必要素材とボタン

レベルアップの条件:

- 自動レベルアップ: 所持経験値が閾値以上（タスク完了時、保存データ読込時、上限解放後に処理）
- 手動レベルアップ: 現在のレベルが上限未満で、硬貨と星屑が足りている（経験値は不要・消費しない）

自動レベルアップの必要経験値:

| 項目 | 計算 |
| --- | --- |
| 必要経験値 | 現在のレベル × 100 |

手動（素材）レベルアップの費用:

| 項目 | 計算 |
| --- | --- |
| 硬貨 | 現在のレベル × 50 |
| 星屑 | 現在のレベル ÷ 2 の切り上げ（最低1） |

例:

| 現在Lv | 必要経験値 | 硬貨 | 星屑 |
| --- | --- | --- | --- |
| 1 | 100 | 50 | 1 |
| 5 | 500 | 250 | 3 |
| 20 | 2000 | 1000 | 10 |

自動レベルアップでは必要経験値を消費し、余った経験値は持ち越される。必要経験値を大きく超えると連続でレベルが上がる。手動レベルアップでは経験値を消費せず、硬貨・星屑のみ消費して1レベル上がる。

ボタンの表示:

- 上限到達: 「レベル上限に到達」
- 素材不足: 「素材が足りません」
- 実行可能: 「素材でレベルアップ（硬貨 N / 星屑 N）」

### 14.5 レベル上限と上限解放

レベル上限は上限解放の段階で決まる。

| 上限解放段階 | 最大レベル |
| --- | --- |
| 0 | 20 |
| 1 | 30 |
| 2 | 40 |
| 3 | 50 |
| 4 | 60 |
| 5 | 70 |

上限解放は、現在のレベルが上限に達していて、必要素材が揃っている場合だけ実行できる。

必要素材:

| 解放段階 | レベル上限の変化 | 結晶 | 専用素材 | 硬貨 |
| --- | --- | --- | --- | --- |
| 1 | Lv.20 → 30 | N結晶 ×3（任意種類） | 素材1 ×3 | 200 |
| 2 | Lv.30 → 40 | R結晶 ×3（任意種類） | 素材2 ×5 | 400 |
| 3 | Lv.40 → 50 | R結晶 ×5（任意種類） | 素材1 ×8 | 700 |
| 4 | Lv.50 → 60 | SR結晶 ×5（任意種類） | 素材2 ×12 | 1100 |
| 5 | Lv.60 → 70 | SR結晶 ×8（任意種類） | 素材1 ×18 | 1600 |

- 結晶は同じレアリティであれば種類を問わない。合算して必要数を満たす。
- 消費する結晶は、所持数の多い種類から優先される。
- 専用素材はキャラクターごとに決まっている。
- 上限解放しても現在のレベルは変わらず、上限だけが上がる。
- 上限解放段階5が最大。
- 条件を満たさない場合、ボタンは押せない。

ボタンの表示:

- 実行可能: 「レベル上限を解放」
- レベル不足: 「Lv.N で解放可能」
- 素材不足: 「素材が足りません」

### 14.6 履歴タブ

- 直近5件の報酬を表示する
- 通貨と経験値
- 獲得した素材
- 日付
- 報酬がない場合は「クエストを完了すると、ここに報酬が記録されます。」と表示される

この履歴はキャラクター別ではなく、アプリ全体の直近の報酬を表示する。

### 14.7 キャラクターがいない場合

所持キャラクターが0人の場合は「キャラクターがいません」「所持キャラクターがいません。」と表示される。通常の操作では発生しない。

## 17. 応援イベント

### 17.1 発生する場面

| 種類 | 発生条件 | メッセージの例 |
| --- | --- | --- |
| 連続作業 | 前回の作業終了から30分以内に次の作業を開始し、休憩を完了していない | 「ここまでよくがんばったね！続けてえらいけど、合間の休憩も大切だよ。応援してる！」 |
| 長時間作業 | 実作業時間が50分以上になったとき（1セッション1回） | 「長時間集中できてるね！水分補給と軽い休憩を忘れずに。無理しすぎないでね」 |
| 休憩完了 | 休憩時間が自動で完了したとき | 「休憩おつかれさま！頭がすっきりしたね。次のクエストもいっしょにがんばろう」 |

### 17.2 話すキャラクター

- 長時間作業: その作業で派遣したキャラクターの先頭が優先される。
- 連続作業: 前回の作業で派遣したキャラクターの先頭が優先される。
- 休憩完了: 休憩元のセッションで派遣したキャラクターの先頭が優先される。
- 派遣がいない場合は、所持キャラクターの先頭。

### 17.3 表示と保持

- 画面下部にトースト表示される。
- 1件ずつ表示される。
- 閉じるボタンで消せる。
- 閉じると確認済みになる。
- 保持できるイベントは最大20件。古いものから削除される。
- 長時間作業の応援は、同じセッションで1回だけ発生する。
- 連続作業の応援は、条件を満たすたびに発生しうる。
- 休憩を早終了した場合は、休憩完了の応援は発生しない。

## 19. 未実装・制限・注意事項

### 19.1 現在の制限

- 同時に進行できる作業は1件だけ。
- 作業時間の通知やアラームはない。
- 予定日・時刻は手入力で、日付選択カレンダーはない。
- 繰り返しは曜日指定の週次のみ。隔週・月次などの設定はない。毎日にするには全曜日を選ぶ。
- 繰り返し予定の開始日・終了日は必須または任意の日付入力で扱う。
- 削除したクエスト、カテゴリー、サブカテゴリーを元に戻す操作はない。
- 作業セッションの時間や探索先を後から修正する操作はない。
- キャラクターの入手、ガチャ、ショップはモバイル版にはない。
- 家具・コスチュームの変更、部屋の模様替えはない。
- アステルは定義のみで、入手手段がない。
- アカウント、クラウド同期、複数端末間の共有はない。
- データのエクスポート・インポートはない。
- Web版とモバイル版のデータは共有されない。
- Web版にはモバイル版にない画面があるが、この文書の対象外。

### 19.2 データに関する注意

- データは端末内に保存される。アプリを削除したり、端末のデータを消去すると進行状況が失われる。
- 保存データの読み込みに失敗した場合、既存データ保護のため自動保存が停止することがある。
- 保存データの形式が壊れている場合は、初期状態で起動し、その後の操作で上書きされる可能性がある。重要なデータのバックアップ機能は現時点では用意されていない。
- 端末の時計を変更すると、経過時間や日付判定が想定と変わることがある。

### 19.3 表示に関する注意

- カテゴリーの色は名前をもとに決まるため、初期カテゴリーを改名すると色が変わる場合がある。
- 履歴の分類名は作業開始時点の名前で表示される。現在の分類名とは異なる場合がある。
- 報酬結果パネルはアプリ再起動後に復元されない。報酬や履歴は保存されている。
- 3Dモデルはルナのみ。ヒナタとアステルは簡易表示。
- 3Dモデルの読み込みに失敗すると簡易表示に切り替わる。
- 画面の英語小見出しやアイコンは装飾であり、操作には影響しない。

### 19.4 仕様上の割り切り

- 週間達成率は、削除による分母操作を完全には防げない。一定の条件で対象外にするのみ。
- 休憩週は連続2週までという制限だけがあり、回数制限はない。
- 週次判定はアプリを開いたときにまとめて行われるため、週明けすぐに判定されないことがある。
- 作業中のアプリ終了はタイマーを止めないため、長時間閉じた場合は実作業時間が長く記録される。
- 60秒未満の作業でも、完了扱いなら結晶・専用素材の抽選は行われる。
- 同じクエストの2回目以降の完了では、結晶・専用素材は出ない。
- 星屑の持ち越しは10分未満の端数分だけ。

## 21. よくある操作

### 21.1 今日の予定を追加したい

1. 出撃タブを開く
2. 「＋ クエストを追加」を押す
3. クエスト名と予定時間を入力する
4. 必要ならカテゴリーと時刻を設定する
5. 「クエストを追加」を押す

### 21.2 予定どおりに作業を始めたい

1. クエストボードからクエストの出撃ボタンを押す
2. 探索先を選ぶ
3. 派遣する仲間を選ぶ
4. 「出撃して作業開始」を押す

予定を決めずに今すぐ始める場合は、次の手順になる。

1. 出撃画面の「⏱ 即時開始」を押す
2. クエスト名と内容を入力する
3. 探索先を選ぶ
4. 派遣する仲間を選ぶ
5. 「ストップウォッチで開始」を押す

### 21.3 作業を一時的に止めたい

1. 探索中パネルの「一時停止」を押す
2. 再開するときは「再開」を押す

一時停止中の時間は報酬や履歴に含まれない。

### 21.4 作業を終えたい

- 予定どおり終えられた場合は「完了して終了」
- 途中で切り上げる場合は「中断して終了」
- 記録を残したくない場合は「記録せず取消」

### 21.5 休憩を取りたい

1. 作業終了後の報酬結果パネルを開く
2. 推奨時間、または好みの時間を選ぶ
3. 時間になると自動で完了する
4. 早めに終える場合は「休憩を終える」

### 21.6 繰り返しの予定を登録したい

1. 出撃タブで「週間計画」を開く
2. 「繰り返し予定」の「追加」を押す
3. 予定名、予定時間、曜日、開始日を入力する
4. 必要なら時刻と終了日を設定する
5. 「繰り返し予定を追加」を押す

### 21.7 キャラクターを育てたい

1. キャラタブ、または拠点の住人からキャラクターを選ぶ
2. 「育成」タブを開く
3. 経験値はタスク完了で貯まり、閾値に達すると自動でレベルアップする
4. 早めに上げたい場合は、硬貨と星屑が足りていれば「素材でレベルアップ」を押す
5. レベル上限に達したら、必要素材を集めて「レベル上限を解放」を押す

### 21.8 施設を強化したい

1. 拠点タブを開く
2. 机（コイン工房）または棚（星屑ハウス）をタップする
3. 通貨が足りていれば「強化」を押す
4. 生産を止めたい場合は「稼働を停止」を押す

### 21.9 週間の達成状況を確認したい

1. 出撃タブの「今日の作戦」を見る
2. 詳しく見る場合は「週間計画」を開く
3. 週間スケジュールで日ごとの完了数と達成率を確認する
4. 連続達成週数とランクは「週間の継続状況」で確認する

### 21.10 過去の作業時間を確認したい

1. 履歴タブを開く
2. 今日・今週・今月・累計の合計を確認する
3. 日 / 週 / 月 / 年 を切り替えて推移を見る
4. カテゴリーで絞り込む
5. 下部のセッション一覧で個別の作業を確認する

### 21.11 分類を整理したい

1. 履歴タブの「分類管理」を押す
2. カテゴリーを追加・改名・並べ替えする
3. 必要ならサブカテゴリーを追加する
4. 使わない分類は削除する

削除しても過去の履歴は残る。

### 21.12 休憩週を設定したい

1. 出撃タブで「週間計画」を開く
2. 「週間の継続状況」の「この週を休憩週にする」または「来週を休憩週にする」を押す
3. 解除する場合は「この週の休憩を解除」または「来週の休憩を解除」を押す

判定済みの週や、連続3週目になる設定はできない。

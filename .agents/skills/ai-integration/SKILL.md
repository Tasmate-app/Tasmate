# AI Integration

## 基本方針
- AI呼び出しは専用のサービス層またはサーバー側関数を経由させる。
- APIキーをフロントエンドに埋め込まない。
- AIの応答形式を検証してからゲームロジックへ渡す。
- AIの自由文だけを報酬確定の根拠にしない。
- 報酬候補の生成と、許可された報酬の確定を分離する。

## 信頼性
- タイムアウト、通信失敗、形式不正、レート制限を考慮する。
- AIサービスが利用できない場合の代替動作を用意する。
- AIが利用できなくても基本的なタスク管理とゲーム進行を止めない。
- AIの出力は形式・範囲・重複付与を検証する。

## テスト
- 実際のAPI呼び出しを行うテストと、モックを使うテストを区別する。
- 正常応答だけでなく、タイムアウト・不正形式・空応答・レート制限を確認する。
- 秘密情報や不要な個人情報をログへ出力しない。

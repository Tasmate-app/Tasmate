# Game Domain Logic

## 基本方針
- ゲームルールをReactコンポーネントに直接埋め込まない。
- 原則として `src/domain/` に配置し、UIや3D描画に依存しない純粋な関数として実装する。
- 3D画面を起動しなくてもゲームロジックをテストできる構造にする。
- 報酬の「決定」と「付与」を分離する。

## 対象機能
- 作業実績に応じた報酬計算
- 素材・通貨・経験値の管理
- キャラクターのレベルアップや能力補正
- 探索・派遣・素材収集
- 施設による素材・通貨の生産
- 家具・施設・コスチュームの購入や強化

## 実装ルール
- 計算の入力と出力を明確にし、単体テストを用意する。
- 数値の上限・下限・負数・欠損・不正な入力を検証する。
- キャラクター属性、探索先、施設レベルなどの補正条件を明示する。
- ゲームバランスに関する数値は、必要に応じて定数や設定へ切り出す。
- バランス値を変更する場合は、関連仕様とテストへの影響を確認する。
- オンライン化後、重要な報酬付与はサーバー側で検証・確定する。
- AIの出力をそのまま信用せず、形式・範囲・重複付与を検証する。
- AIが利用できなくても、基本的なタスク管理とゲーム進行を停止させない。

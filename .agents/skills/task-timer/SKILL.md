# Task and Timer

## 基本方針
- ゲーム要素は現実の作業継続を支援するためのものであり、タスク管理やタイマーの使いやすさを損なわない。
- タスクの登録・編集・開始・終了を少ない操作で行えるようにする。
- タイマーの状態遷移を明確にする。

## タイマー実装
- 経過時間を一定間隔のカウントアップ処理だけに依存させない。
- 作業開始時刻を基準に経過時間を算出する。
- ページ再読み込みやタブのバックグラウンド化に対応する。
- 一時停止・再開・終了の状態遷移を明確に定義する。
- 日付・タイムゾーンは保存形式と表示形式を区別する。

## 履歴と報酬
- 作業履歴には必要な開始時刻、終了時刻、経過時間、タスク識別子を保存する。
- 重複した完了処理で報酬が二重付与されないようにする。
- ローカル時刻やブラウザ状態だけを信頼して、将来のオンライン環境で報酬を確定しない。
- 報酬計算そのものは `game-domain` Skillの方針に従い、UIやタイマー処理から分離する。

## テスト対象
- 開始・一時停止・再開・終了
- リロード後の作業状態の復元
- バックグラウンドタブでの経過時間
- 日付境界・タイムゾーン
- 完了処理の重複と二重報酬の防止
